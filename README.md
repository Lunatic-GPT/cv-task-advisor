# CV Task Advisor

[English](README.en.md) | 中文

**给不熟悉计算机视觉的人用的“任务 → 论文 → 基线”顾问 Skill，支持中英文。**

你有一个真实任务，想用深度学习 + 计算机视觉解决，但不知道它属于哪类 CV 问题、该看哪些论文、数据要准备到什么程度。这个 Skill 会用**白话**访谈你的任务和数据，把它映射到最接近的 CV 任务，再从 223 篇代表性论文中挑出 3–6 篇最相关的，并说明它们的代码、数据集规模和预处理方式。

## 它解决什么问题

很多 CV 调研工具一上来就要求你说出“分类 / 检测 / 分割 / 跟踪”这些术语。但业务方通常只知道：

- 我手上有工地监控视频，想自动发现没戴安全帽的人；
- 我有一批零件照片，想挑出有划痕的；
- 我有一堆医学影像，想勾出病灶；
- 我有一组卫星图，想知道哪里新建了房子。

这个 Skill 不要求你懂术语。它会问：

1. **你的任务是什么？**（用你平时跟同事说话的方式）
2. **你的数据长什么样？**（来源、数量、标注、拍摄条件、预处理）
3. **谁用、用来做什么决定、什么算做得好？**

然后复述成一张“任务卡”，确认无误后再检索论文。

## 快速开始

### 方式一：直接打开本仓库

在 Claude Code 中打开本仓库根目录。`.claude/skills/cv-task-advisor/` 会被自动加载。

```text
/cv-task-advisor
```

### 方式二：复制到现有项目

```text
your-project/
├── .claude/
│   └── skills/
│       └── cv-task-advisor/
│           ├── SKILL.md
│           └── references/task-map.md
└── knowledge/
    └── CV_Topics_2016-2025_*.md
```

把本仓库的 `.claude/skills/cv-task-advisor/` 复制到你的项目 `.claude/skills/`，把 `knowledge/` 复制到项目根目录或 `knowledge/`。Skill 会自动搜索这两个位置。

也可以直接用自然语言触发，例如：

> 我有一个新任务，想用计算机视觉做，但不知道参考哪些论文。

Skill 支持中英文：用英文描述任务，它会用英文访谈、复述和输出；知识库是中文的，但会用英文转述，不会把中文段落直接贴给你。

## 它会输出什么

```markdown
## 一句话结论
你的任务最像“开放词汇目标检测”，先看 Grounding DINO，再看 YOLO/DETR 系列。

## 1. 你的任务（复述）
- 输入：工地监控视频，固定机位，白天/夜间都有
- 输出：每一帧里“人 + 安全帽”的位置，以及是否佩戴
- 用途：安全员告警
- 成功标准：漏报尽量少，误报可接受

## 2. 数据画像
- 数据类型：视频抽帧
- 规模与标注：约 2,000 张，计划标框
- 现有预处理：无
- 采集条件：光照变化、遮挡、远距离小目标
- 隐私/实时/部署约束：需要实时，工人面部需脱敏

### 2.1 参考工作的数据条件
| 论文 | 主要数据集与规模 | 典型预处理 | 和你的差异 |
|---|---|---|---|
| YOLO | COCO，11.8 万图 | resize 800、翻转、归一化 | 你的数据少 2 个数量级，先微调 |

## 3. 最接近的 CV 任务
主任务：目标检测（#18）
辅助任务：多目标跟踪（#66）

## 4. 推荐论文
| 论文 | 年份/会议 | 它解决什么 | 为什么适合你 | 可借鉴点 | 代码 |
|---|---|---|---|---|---|
| YOLO | 2016 / CVPR | 单阶段实时检测 | 需要实时 | 单阶段框架、数据增强 | 官方开源 |
| DETR | 2020 / ECCV | 端到端集合预测 | 减少后处理 |  Transformer 检测头 | 官方开源 |
| ByteTrack | 2022 / ECCV | 多目标跟踪 | 减少告警闪烁 | 低分框二次关联 | 官方开源 |

## 5. 建议的基线方案
1. 抽帧，按 1 fps 抽样，去重；
2. 标 1,000–2,000 张，先标“人”和“安全帽”两类；
3. 用 COCO 预训练的 YOLO 微调；
4. 加入跟踪，按“人-帽”配对做规则判断；
5. 按漏报率、误报率、延迟评估。

## 6. 数据与标注建议
```

## 工作流

| 阶段 | 做什么 |
|---|---|
| Phase 0 | 读取任务映射表和知识库 |
| Phase 1 | 白话任务访谈，一次只问一个问题 |
| Phase 2 | 白话数据访谈：规模、标注、采集条件、预处理 |
| Phase 3 | 复述“任务卡”，让用户确认 |
| Phase 4 | 映射到 1 个主任务 + 1–2 个辅助任务 |
| Phase 5 | 从知识库检索 3–6 篇论文，说明代码与数据条件 |
| Phase 6 | 给出基线方案、标注建议、指标、风险、一周试点 |

## 知识库

本仓库附带一套从 2016–2025 年 CVPR / ICCV / ECCV / ICML / NeurIPS / ICLR / AAAI 文献中整理的 CV 主题与论文知识库：

| 文件 | 内容 |
|---|---|
| `CV_Topics_2016-2025.md` | 334 个 CV 主题，含活跃年份、趋势、主要会议 |
| `CV_Topics_2016-2025_plain.md` | 334 个主题的“小白版”解释，每个 3–5 句 |
| `CV_Topics_2016-2025_references.md` | 223 篇代表性论文，按 18 个领域分组 |
| `CV_Topics_2016-2025_code_availability.md` | 223 篇论文的代码状态与仓库链接 |
| `CV_Topics_2016-2025_data_profiles.md` | 223 篇论文的数据集、规模、预处理与提示 |

CSV 版本在同一目录下，方便排序和筛选。

### 代码状态

- 165 篇官方开源（GitHub / 作者主页 / HuggingFace）
- 14 篇第三方复现
- 13 篇仅数据集/评测
- 13 篇未开源
- 18 篇待核实

“官方开源”不等于开箱即用：不少是研究代码，依赖旧框架、需要申请数据或模型权重。

### 数据规模

覆盖从 30 张图的 U-Net、每主体 3–5 张的 DreamBooth，到 1.28M 图的 ImageNet、4 亿图文对的 CLIP。数据规模为论文主实验常用基准的近似值，具体以论文为准。

## 设计原则

- **不要求用户懂术语。** 问“你想让电脑输出什么”，而不是“你要做分类还是分割”。
- **一次只问一个问题。** 不发问卷。
- **先复述，再检索。** 避免理解错任务就推荐论文。
- **论文少而准。** 最多 6 篇，按“为什么适合你”排序。
- **明确说“不像”。** 相似任务不等于同一个任务。
- **数据决定方法。** 数据少 1–2 个数量级时，先推荐预训练/少样本，而不是从零训练。
- **不编造论文。** 不确定的年份、会议、代码状态会标注“待核实”。

## 限制

- 知识库是人工整理的精选列表，不是全量文献数据库。没有覆盖到的方向会用 WebSearch 补充。
- 论文的“代表性”有主观判断，欢迎提 issue 补充。
- 数据集规模是近似值，训练细节请以论文原文和官方代码为准。
- 代码状态核对停留在“仓库是否存在”，没有逐篇验证能否复现论文数字。
- 医学、人脸、自动驾驶等高风险场景，需要额外的合规、伦理和人工复核，Skill 会提示但不能替代。
